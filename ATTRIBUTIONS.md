# Attributions

mbwishlist.online is a single self-contained HTML file with no build step,
no bundled third-party JavaScript libraries, and no icon library or stock
image assets. It loads nothing from any third-party server.

## Fonts

None are bundled or downloaded. The page uses the fonts already installed
on the visitor's device (Segoe UI, system-ui, -apple-system, Roboto,
Helvetica/Arial and their monospace equivalents).

## Everything else

- **Icons:** Small inline SVG line icons drawn for this app, plus a few
  Unicode characters (★ ↑ ↓ –). No icon font or third-party icon library.
- **App icon:** `favicon.svg` (Matthew's bag-and-heart mark), with
  `favicon.ico`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` and
  `apple-touch-icon.png` rendered from it. Original artwork.
- **Decorative art:** the flat "paper cutout" hills, sun, leaves and seed
  shapes (templates NA-06 and NA-16) come from Matthew's own MB Suite theme
  kit, shared across his mb apps. Original artwork.
- **Shared app code:** `MBTitle`, `MBInstall` and `MBShare` (tab titles,
  the Install card and share images) are inlined from the same MB Suite kit.
  Original, written for these apps; no third-party code.
- **Images:** No stock photography, logos, or bundled images. Product
  thumbnails come only from photos a user uploads themselves. `og-image.png`
  is generated from the app's own screenshot and artwork.
- **Code:** No third-party JavaScript libraries, frameworks, or CDN
  scripts. All logic is original, hand-written vanilla JavaScript in the
  page itself and in `sw.js` (the offline service worker).
- **Retailer names** (e.g. "Amazon," "Walmart," "Target") that appear as
  small labels on items are the trademarks of their respective owners.
  They're shown only to describe a link the user chose to paste. See the
  app's FAQ for the no-affiliation note.
