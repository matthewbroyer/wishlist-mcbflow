# Release notes · Wishlist (wishlist.mcbflow.com)

Newest first. One entry per release, in plain words a user would understand.

## 1.5 · 2026-10-16
- New Settings page (the gear at the bottom of the sidebar; the first item under More on phones): theme, account and sync, list layout, backups, install and app info in one place. The old FAQ page is now **Help**, and the "Privacy & storage" note moved into Settings → Backup & data.
- Account button in the top bar: "Sign in", or once you're signed in your profile picture with a small sync dot. Edit profile lets you pick a screen name and one of the profile pictures; every mcbflow.com app shows the same ones. New "Keep me signed in on this device" switch (turn it off on a shared computer).
- A greeting above My list: "Good morning", with your name when you're signed in.
- New welcome screen, the same in every mcbflow.com app: what Wishlist does, light or dark, then start with the sample list or an empty one. You can sign in or import a backup right from it. The separate "Privacy & storage" pop-up is gone; its message is on the first step.
- Clearer Data menu, in the same order as the other apps, and every item says what it does. New **Export All (ZIP)**: your backup, a spreadsheet and all your item photos in one file. **Import Backup** reads JSON or ZIP files. The backup file location and "Change location…" are in Settings.
- Tap an item photo (card, table, Purchased, Compare, review, or the edit window) to see it full size in the app, with arrows between the photos on screen. Product links still open the store as before.
- Signed in and syncing: no backup warnings. The backup chip reads "Synced" and the Data menu says "Synced to your account".
- Even top bar (every button the same height), the new name style "Wishlist ∙ mcbflow.com", the standard gear (Settings) and question-mark (Help) icons, and a short footer with What's new, Privacy, Terms and More free apps.
- Backups now say `"app": "wishlist"` inside the file. Older backups still import the same way.

## 1.4 · 2026-10-15
- New: optional sync across devices. Data → Sync across devices signs in with a free mcbflow.com account; items, prices and history then match on every device you sign in on.
- Item photos stay on the device where you added them; other devices show the item without its photo. Sample items never sync.
- Not signed in: nothing changes. Clearing items or all data warns when you're signed in.

## 1.3 · 2026-10-14
- Moved to wishlist.mcbflow.com. Data saved at the old address doesn't carry over: export a backup there and import it here.
- Storage names simplified.

## 1.2 · 2026-10-14
- On computers, the search box, backup status and logo spacing now look exactly like the other mb apps: same size, same "Search…" text, and the "/" key now jumps to search.
- Icons are back everywhere. The top bar, the bottom bar on phones, menus and buttons had been showing blank boxes because the icon set was missing from the page.
- The top bar now looks and works the same as in the other mb apps. On phones it shows Search, Data, the light/dark switch and Add item as square icon buttons next to the logo.

## 1.1 · 2026-10-14
- New logo, redrawn in the same style as the other mb apps (app icon, tab icon, share image and pages all updated).

- About card at the bottom of the FAQ page: version, release date, links and copyright in one place. The Install card moved from the top of the FAQ down next to it.
- Installing from matthewbroyer.com: the hub's Install button opens the app with a short install prompt.
- New "page not found" page that matches the app and links back to it.
- Version numbers restart at 1.x with the suite's "Official Web App" label; earlier releases were numbered v1.5 to v1.9 (the entries below use those build numbers).

## 2026-10-13 · v1.9

- New layout shared with the other mb apps: your sections are in a left sidebar (an icon rail on tablets, a bottom bar on phones), and the logo always takes you back to your list.
- The first section is now called **My list**, and browser tabs read "Wishlist | My list", "Wishlist | Purchased" and so on.
- Share your progress from the Purchased tab as a square image made on your device: how many planned things you bought, how many you decided against, and how many are still on your list. Item names never go on it; dollar amounts only if you turn them on.
- Install card at the top of the FAQ ("Install Wishlist" in Chrome and Edge, Add to Home Screen steps on iPhone). The installed app is now named "Wishlist".
- Items with a store link can be moved to Purchased again. Buy now only opens the store page (since v1.7), which left linked items with no direct way to mark them bought. Now there's a check mark next to edit and delete, a Mark purchased button in the edit window, and a "Bought it? Mark purchased" prompt right after Buy now.
- Buttons, links and the selected section use a deeper amber so text is easier to read.
- The search box and filters sit in one row on wider screens instead of stacking.
- Dialogs move keyboard focus inside when they open, keep Tab inside, and hand focus back when they close.
- Link previews (Facebook, iMessage, Slack and others) now show a proper title, description and image.
